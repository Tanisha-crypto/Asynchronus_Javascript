# 🚦 Traffic Light Simulator

Traffic Light Simulator is a simple web app that simulates a real traffic light sequence with automatic color changes and a countdown timer.

## ✨ Features

- Automatic red, yellow, and green light cycle
- Live countdown timer
- Start, stop, and reset controls
- Clear status text for traffic flow
- Beginner-friendly JavaScript project

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/Tanisha-crypto/Traffic_Light
```

Open `index.html` in your browser to run the simulator.

## 🎮 How to Use

1. Open the app in your browser.
2. Click the Start button to begin the traffic light cycle.
3. Watch the active light and countdown timer.
4. Use Stop to pause the sequence or Reset to restart it.
