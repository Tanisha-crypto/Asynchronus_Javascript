# 🕒 Digital Clock

Digital Clock is a simple web application that displays the current time and updates every second.

## ✨ Features

- Displays the current local time
- Uses a 12-hour time format with AM/PM
- Updates the time every second
- Simple and clean user interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Tanisha-crypto/Digital_Clock.git
```

Then open `index.html` in your browser. No installation or build setup is required.

## 🎮 How to Use

1. Open `index.html` in a browser.
2. The clock will display your current local time.
3. The displayed time updates automatically every second.
