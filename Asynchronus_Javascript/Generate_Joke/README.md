# 😂 Random Joke Generator

Random Joke Generator is a fun web app that fetches and displays random jokes using an API.

## ✨ Features

- Fetches a random joke from an API
- Displays joke setup and punchline
- Simple button-based interaction
- Clean and responsive user interface
- Beginner-friendly JavaScript project

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Joke API

## 🚀 Getting Started

```bash
git clone https://github.com/Tanisha-crypto/Generate_Joke
```

Open `index.html` in your browser to use the app.

## 🎮 How to Use

1. Open the app in your browser.
2. Click the Generate Joke button.
3. Read the setup and punchline.
4. Keep generating jokes whenever you want.
