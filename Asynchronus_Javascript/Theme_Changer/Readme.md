# 🎨 Theme Changer

Theme Changer is a simple interactive web project that allows users to switch the appearance or theme of a webpage.

## ✨ Features

- Change webpage themes dynamically
- Interactive theme controls
- Simple and clean UI
- Instant visual updates
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/Tanisha-crypto/Theme-Changer
```

Open `index.html` in your browser.

## 💡 How It Works

JavaScript handles the user's theme selection and updates the webpage styling dynamically.
