# 💱 Currency Converter

Currency Converter is a simple web application that converts an amount from one currency to another using live exchange rates.

## ✨ Features

- Converts amount between different currencies
- Supports multiple currencies like USD, INR, EUR, GBP, and JPY
- Simple and clean user interface
- Fetches real-time conversion rates from an API
- Displays the converted result instantly

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Frankfurter API

## 🚀 Getting Started

```bash
git clone https://github.com/Tanisha-crypto/Currency_Converter
```

Open `index.html` in your browser to use the app.

## 🎮 How to Use

1. Enter the amount you want to convert.
2. Select the currency you are converting from.
3. Select the currency you want to convert to.
4. Click the Convert button.
5. View the converted result on the screen.
