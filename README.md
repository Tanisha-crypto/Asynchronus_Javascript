# Asynchronous JavaScript Projects 🚀

This repository contains a collection of JavaScript projects created to understand and practice **Asynchronous JavaScript** concepts and API-based web development.

The projects demonstrate concepts such as **Promises, async/await, Fetch API, timers, DOM manipulation, event handling, and working with external APIs**.

## 📂 Projects

### 1. Currency Converter 💱
A currency conversion application that fetches exchange-rate data and converts one currency into another.

**Concepts Used:**
- Fetch API
- Async/Await
- API handling
- DOM Manipulation
- Event Handling

---

### 2. Digital Clock 🕐
A simple digital clock that displays the current time and updates automatically.

**Concepts Used:**
- JavaScript Date Object
- setInterval()
- DOM Manipulation
- Event Handling

---

### 3. Generate Joke 😂
An application that fetches and displays random jokes using an external API.

**Concepts Used:**
- Fetch API
- Promises
- Async/Await
- API Integration
- DOM Manipulation

---

### 4. Recipe Finder 🍴
A recipe-search application that retrieves recipes based on user input.

**Concepts Used:**
- Fetch API
- Async/Await
- API Integration
- Search functionality
- DOM Manipulation

---

### 5. Theme Changer 🎨
A project that allows users to change the website theme dynamically.

**Concepts Used:**
- DOM Manipulation
- Event Listeners
- CSS
- JavaScript

---

### 6. Traffic Light 🚦
A traffic light simulation created using JavaScript.

**Concepts Used:**
- setTimeout()
- setInterval()
- DOM Manipulation
- Conditional Logic
- Event Handling

---

### 7. Weather App 🌤️
A weather application that fetches weather information based on a location.

**Concepts Used:**
- Fetch API
- Async/Await
- API Integration
- JSON
- DOM Manipulation
- Error Handling

---
